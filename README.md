# 📍 Buscador de CEP

Projeto desenvolvido com **HTML, CSS e JavaScript** para consultar endereços automaticamente por meio da API ViaCEP.

## 🚀 Funcionalidades

- Consulta de endereço pelo CEP.
- Validação inicial de 8 caracteres.
- Preenchimento automático de logradouro, bairro, cidade e estado.
- Tratamento básico de erros.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- ViaCEP

## 📚 Conceitos praticados

- Manipulação do DOM
- Eventos com `addEventListener()`
- Requisições HTTP com `fetch()`
- Promises com `.then()`
- Tratamento de erros com `.catch()`
- Consumo de APIs REST

## 💻 Como executar

1. Clone ou baixe o repositório.
2. Abra o projeto no VS Code.
3. Execute o arquivo `index.html` no navegador.
4. Digite um CEP válido e saia do campo para consultar o endereço.
